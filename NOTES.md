## Правила, выработанные на практике
- Дизайн сайтов — строго по `AI-RULES.md` (§0 перед вёрсткой, §9 перед сдачей). Оригинал правил: Google Drive, файл id `1rd1dZONqPJf3UXt9t2hjgygqOuZL1ibm` (прямая загрузка: `https://drive.usercontent.google.com/download?id=1rd1dZONqPJf3UXt9t2hjgygqOuZL1ibm&export=download&confirm=t`).
- Лиды: только МОБИЛЬНЫЕ номера (+7 70x, 747, 771, 775–778) — на городских нет WhatsApp. Каждую компанию проверять поиском: у части клиник из справочника сайт на самом деле есть, а часть уже закрылась.
- Владельцев в справочниках нет — не выдумывать. Директора можно искать по названию ТОО на statsnet.co / kompra.kz.
- На демо-сайтах не выдумывать факты о клинике (годы, цены, «под микроскопом»). Неподтверждённое — в список «сверить с клиникой».
- Кнопки: запись в WhatsApp (`wa.me/7…?text=…`), номер текстом в шапке, контактах и на нижней плашке. `tel:` не работает на компьютере и в просмотрщике claude.ai → окно с номером, «Скопировать номер», WhatsApp.
- Анимации — anime.js + Motion из npm (`npm pack animejs motion`, UMD в `vendor/`).
- Капчи и антиботы (2ГИС, Unsplash, Pexels, YouTube) не обходить.

## Особенности облачного окружения
- Сеть открыта (Full). Внешние сайты проверять только по `https://` — `http://` не резолвится.
- Справочник Zoon.kz работает через POST `…/medical/?action=listJson&type=service` (метод расписан в `.claude/agents/lead-finder.md`).
- Фото для демо: Wikimedia Commons (API со своим User-Agent), одна обработка через ffmpeg, авторов — в подвал.
- Playwright и Chromium предустановлены: `require('playwright')`, `playwright install` не запускать.
- Контейнер стирается между сессиями: всё важное коммитить в репозиторий.
